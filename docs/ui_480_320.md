#LCD ui concept

## Monitor screen
ased on 3x4 greed layout


### Running
```
----------------------------------------
| [Profile] 8 | [out1]  [out2]  [out3] |
----------------------------------------
| [Step] 88   |                        |
---------------          150c          |
| [Power] 100 |                        |
----------------------------------------
| [Monitor] [Edit] [Settings] [Events] |
----------------------------------------
```

### Idle
```
----------------------------------------
|             |                        |
----------------------------------------
|             |                        |
---------------          150c          |
|             |                        |
----------------------------------------
| [Start]  [Edit]  [Settings] [Events] |
----------------------------------------
```

--------------------------------
